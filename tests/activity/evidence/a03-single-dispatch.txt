row A03 - single-dispatch code review (static evidence, repo HEAD 2711907a)

Every activity launch and lifecycle entry in lane-C-owned code enters exactly ONE
dispatcher: ATLActivityController.hostEvent(int,Object) and the one process-wide
controller returned by ATLActivityController.get(). There is no second
launcher/service path, and no per-call-site transition logic.
